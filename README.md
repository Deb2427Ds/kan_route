# KAN-Route

Code for **KAN-Route: Robust and Interpretable Multimodal Tool Routing under Synthetic-Teacher Distribution Shift**
(KAN vs MLP routing heads over frozen MiniLM text and CLIP image embeddings; 28-tool Shared-28 taxonomy;
Qwen2.5-7B / Llama-3.1-8B synthetic teachers; 372 human-written queries).

This repository contains **code only**: Kaggle notebooks and helper scripts. Datasets, checkpoints, predictions,
CSVs, figures and tables are generated by the notebooks and are not stored here (see `.gitignore`).
Notebook outputs have been stripped.

## Layout (in the order the work was done)

| Folder | Stage |
|---|---|
| `01_pre_csv_making/` | Early parts 1, 2, 5, 6, 7 and the Qwen / Llama corpus notebooks, plus the first cross-teacher notebook (35-tool, pre leakage-safe split; exploratory) |
| `02_csv_making/` | Construction and cleaning of the human-written benchmark (518 written, 372 in Shared-28) |
| `03_post_csv_pre_part3_4/` | `v3` and `v4`: Shared-28 taxonomy, leakage-safe union-find split, pixel-CLIP embedding generation, pre-run checks and blockers; part-3 / part-4 evaluation scripts |
| `04_part4_post_csv/` | Part 4: three-seed Qwen / Llama / Mixed training, cross-teacher, image-disjoint and human evaluation |
| `05_part5/` | Part 5: seed-fix retraining of all 18 models, leakage re-audit, known/new image analysis, remaining sections |
| `06_neurocomputing_final_experiments/` | `nb1` parameter-matched MLP + linear baseline, `nb2` zero-shot LLM routers, `nb3` latency, statistics and annotation kit |

Files named `*_kaggle_source.py` are the raw script sources saved by Kaggle for a notebook version.

## Running

All notebooks were run on Kaggle (GPU T4). Attach the datasets named in the first markdown cell of each notebook,
then Run All. `nb2` needs a Kaggle secret `HF_TOKEN` (Llama-3.1 is a gated model).
Python dependencies are listed in `requirements.txt`.

FastKAN (<https://github.com/ZiyaoLi/fast-kan>) is a third-party library and is not vendored here:
`git clone https://github.com/ZiyaoLi/fast-kan` and add it to `PYTHONPATH` where a notebook expects it.

## Protocol

Seeds 42, 123, 2026 (set before model construction); results are mean ± sample SD over seeds.
The Shared-28 split manifests are frozen once built.
